## ▶️ How to Run

**1. Clone the repository**

```bash
git clone https://github.com/vishal-developer1/Java-Daily-Coding.git
```

**2. Navigate to the project directory**

```bash
cd Java-Daily-Coding
```

**3. Compile your Java program**

```bash
javac Main.java
```

**4. Run your Java program**

```bash
java Main
```
